# محرّك الرسم المتقدم (اختياري)

هذا الاستوديو يعمل مستقلاً بالمسار الخفيف (`scripts/make_reel.sh`: قص سكتات + كابشن محروق + مقدمة/نهاية بألوانك). يكفي لأغلب الريلات.

للموشن قرافيكس الأعلى (أرقام تتحرك بسلاسة، عناصر تمر خلف الرأس، ستوديو تعديل مرئي، أوضاع البودكاست والمونتاج)، يمكن توصيل محرّك رسم ناضج مفتوح المصدر يعمل **كله على جهاز المستخدم** ولا يرفع الفيديو لأي خادم:

- **video-ad-editor** — Majed Alzaabi — https://github.com/majedphotos/video-ad-editor (رخصة MIT)
- **reel-studio** — Mohamed Abdou — https://github.com/mohamedabdou-ai/reel-studio (رخصة MIT)

هذا الاستوديو مبني على أفكار من هذين المشروعين (انظر `NOTICE.md`).

## كيف توصّله
1. ثبّت محرّك الرسم كإضافة مستقلة في Claude Code (انظر README الخاص بكل مشروع — غالباً `/plugin install` أو وضع مجلد السكل في `~/.claude/skills/`).
2. عند طلب موشن متقدم، مرّر للمحرّك:
   - الفيديو المقصوص و`caps.json` (الكابشن بتوقيت الكلمة).
   - **ألوان وخطوط الهوية** من `build/theme.resolved.json` (الأساسي، التمييز، الكابشن، الخط) — افرضها على إعدادات المحرّك بدل ألوانه الافتراضية.
   - قائمة الكلمات الساخنة وخطة المشاهد (من `motion-and-numbers.md`).
3. المخرَج يعود MP4؛ أكمل خطوات المقدمة/النهاية/الفحص/الصوت كما في SKILL.

## ملاحظة ترخيص
المشروعان أعلاه برخصة MIT: يسمح بالاستخدام والاقتباس مع الإبقاء على حقوق النشر والترخيص. لا تنسخ ملفاتهما داخل هذا المستودع؛ ثبّتهما بشكل مستقل وأبقِ `NOTICE.md` كما هو.
