# استوديو ريلز إسماعيل كبول · ismail-reel-studio

إضافة (Plugin) لـ Claude تحوّل **فيديو كلام أمام الكاميرا + سكريبت مالي** إلى **ريل إنستغرام 9:16 احترافي** بهويتك: قص السكتات، كابشن عربي بتوقيت الكلمة بألوانك وخطوطك، موشن للأرقام، بي-رول لخلايا الإكسل، مقدمة ونهاية ودعوة إلى أكاديميتك. المونتاج كله كود، ويعمل **على جهازك** (الفيديو لا يُرفع لأي خادم).

مبني على أفكار مشروعين مفتوحين برخصة MIT (انظر `NOTICE.md`)، ومخصّص لأسلوب محتوى صفحة **@ismail.accountant** (بنية المحطات التسع، كسرة «لأ.»، ربط كل ريل بملف إكسل مغناطيس).

---

## ما الذي يفعله
- **قص السكتات** تلقائياً وضبط الإيقاع (مع حفظ سكوت «لأ.» المتعمّد).
- **كابشن عربي بتوقيت الكلمة** (Whisper)، بألوان وخطوط هويتك، لا يقع على وجهك ولا في منطقة إنستغرام.
- **موشن للأرقام:** الرقم المهم يظهر بقفزة بلون التمييز، والرقم الخاطئ يُشطب، والرقم السنوي يملأ المنتصف.
- **بي-رول خلايا الإكسل:** إبراز الخلية المقصودة من ملفك المغناطيس أثناء الشرح.
- **مقدمة ونهاية ودعوة** بهويتك، مع رابط الحجز.
- **فحص المناطق الآمنة** ومعايرة الصوت −14 LUFS، ثم **كابشن ووصف جاهزان للنشر**.

## المتطلبات
- Claude Code (الطرفية أو تطبيق الديسكتوب).
- `ffmpeg` و`python3` (إلزامي). `whisper` (اختياري، للكابشن بتوقيت الكلمة).
- للموشن المتقدم: محرّك رسم اختياري (`references/engine.md`).

## 1) أضف الإضافة إلى Claude

### الطريقة أ — إضافة من GitHub (المفضّلة، «أضف الرابط»)
بعد رفع هذا المستودع إلى حسابك (القسم 3)، في Claude Code اكتب:

```
/plugin marketplace add ismailkb551/ismail-reel-studio
/plugin install ismail-reels@ismail-reel-studio
```

- الأول يضيف هذا المستودع كـ«سوق إضافات».
- الثاني يثبّت الإضافة. أعد تشغيل الجلسة إن طُلب.
- للتحديث لاحقاً: `/plugin marketplace update ismail-reel-studio`.

### الطريقة ب — مجلد سكل شخصي (بلا GitHub)
انسخ مجلد السكل إلى مجلد السكلات عندك:
- ماك/لينكس: `~/.claude/skills/ismail-reels/`
- ويندوز: `%USERPROFILE%\.claude\skills\ismail-reels\`

انسخ محتوى `skills/ismail-reels/` إلى هناك، واحتفظ بمجلدي `brand/` و`scripts/` و`presets/` بجانبه (أو عدّل المسارات في SKILL).

---

## 2) خصّص هويتك (ملف واحد)
افتح **`brand/THEME.json`** وضع ألوانك وخطوطك وشعارك ونصوص المقدمة/النهاية/الدعوة، ثم:

```
python3 scripts/apply_theme.py brand/THEME.json
```

التفاصيل الكاملة في `brand/README.md`. القيم الافتراضية: كحلي #1F3864 + ذهبي #E8B23A، خط Tajawal/Cairo — **غيّرها بألوان علامتك**.

## 3) استخدمه
في جلسة Claude Code، أرسل فيديو الكلام وقل مثلاً:
> «حوّل هذا الفيديو لريل» · «ركّب كابشن» · «منتج هذا المقطع»

أرفق سكريبت الريل (بنية المحطات التسع) وملف الإكسل المرافق إن وُجد. Claude يجهّز كل شيء ويريك لقطة بعد كل مرحلة، ويسلّم MP4 + كابشن ووصف جاهزين.

للمسار السريع المستقل:
```
bash scripts/make_reel.sh <input.mov> [captions.srt]
```
